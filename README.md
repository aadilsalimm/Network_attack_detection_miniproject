# Real-Time DoS Attack Detection and Mitigation Using Machine Learning


A machine learning-based prototype to detect and mitigate Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS) attacks in real-time by analyzing network traffic.

## About The Project

In today’s highly connected digital environment, organizations and networks face increasing threats from Denial-of-Service (DoS) attacks. These attacks disrupt critical services by overwhelming network resources with malicious traffic, leading to downtime, financial losses, and compromised user trust.

This project addresses the challenge of detecting and mitigating DoS and DDoS attacks by analyzing real-time network traffic and leveraging machine learning models. The goal is to build a system capable of identifying malicious activity with high accuracy and implementing automated mitigation strategies to ensure the stability and security of network services.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Python and pip installed on your system.
* **pip**
    ```sh
    python -m pip install --upgrade pip
    ```

### Installation

1.  **Clone the repository**
    ```sh
    git clone https://github.com/aadilsalimm/Network_attack_detection_miniproject
    ```
2.  **Navigate to the project directory**
    ```sh
    cd Network_attack_detection_miniproject
    ```
3.  **Install required packages**
    ```sh
    pip install -r requirements.txt
    ```
    *(Note: You will need to create a `requirements.txt` file by running `pip freeze > requirements.txt` in your project environment.)*

## Usage

Navigate to the project directory, then run:
```sh
    python app.py
```
